## List of intended changes

### Ethereum Mainnet

**Approve the Safe transaction migrating the USDC, AUSD and RLUSD vaults**

- Records the Grove SubProxy's `approveHash` on the 2-of-2 Safe that owns the three Vault V2 vaults
- Steakhouse approved on 2026-09-10, so this is the second and final approval; any account can call `execTransaction` afterwards
- The spell itself only approves, so no vault role changes here and the Safe nonce stays `0`

| parameter        | value                                                                |
| ---              | ---                                                                  |
| safe             | `0xD700038b3f8d2F1a8193F35d7dD25c02e7155427`                         |
| transaction hash | `0x8856a205b4c0b0eac9dad69a0c756eb7effa1d42134fccbc66dda1e8a85c32d8` |
| safe nonce       | `0`                                                                  |

**Offboard four ERC-4626 deposit rate limits**

- Grove stops allocating to these vaults; the withdraw keys stay unlimited so existing positions remain redeemable
- RLUSD carries 18 decimals, so the Sentora RLUSD Main row is `e18` while the USDC and PYUSD rows are `e6`

| parameter         | before | after   |
| ---               | ---    | ---     |
| max exchange rate | `0`    | `4e24`  |

Set via `setMaxExchangeRate(vault, 1e18, 4e6)`; the stored rate is 1e36-scaled, so `1e36 * 4e6 / 1e18` = `4e24`. Required before the first deposit, which reverts while the mapping reads `0`.
